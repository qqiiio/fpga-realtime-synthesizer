# 实验与构建证据

- `32voice_spectrum.png`：32 声部 ModelSim 时域与频谱图。
- `32voice_metrics.csv`：32 声部输出 RMS、峰值和峰均比。
- `32voice_peaks.csv`：32 个目标音高的检测频率。
- `fx_impulse_response.png`：四种效果的 ModelSim 冲激响应。
- `fx_metrics.csv`：延迟、合唱与双反射峰值数据。
- `gowin66_resource_report.txt`：66 稳定版 Gowin 资源报告。
- `gowin66_timing_report.tr`：66 稳定版静态时序报告。

频谱和效果仿真采用 46.875 kHz 名义采样率。最终上板时钟以 66 版 PnR/STA
报告为准。
